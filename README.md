# TrustVault - Secure Authentication Portal

A modern, responsive, and feature-rich front-end authentication UI designed with glassmorphism, animated gradients, and rich interactive components.

## 🚀 Key Features

- **Dynamic Mesh Gradient Background:** Smooth animated visual effects.
- **Glassmorphism UI:** Ultra-sleek translucent login container.
- **Multi-Theme Toggle:** Switch easily between **Default**, **Cyberpunk**, and **Emerald** themes.
- **Interactive Security Components:**
  - Password visibility toggle.
  - Live password strength indicator.
  - Active Caps Lock detection.
  - Passkey / Biometrics trigger simulation.
  - Social OAuth buttons (Google, GitHub, Apple).
- **Responsive & Accessible:** Works seamlessly across mobile, tablet, and desktop viewports.

## 📁 File Structure

```
trustvault-frontend/
├── index.html        # Main HTML file containing styling and interactive logic
└── README.md         # Project documentation and setup guide
```

## 🛠️ How to Customize & Deploy

1. Open `index.html` in any modern web browser or code editor (VS Code, Sublime Text).
2. Modify the CSS variables inside `:root` to customize the primary brand colors.
3. Integrate with your backend API (Node.js, Firebase, Supabase, Auth0, FastAPI) inside the `handleLogin` function.
4. Deploy easily to **Vercel**, **Netlify**, or **GitHub Pages**.
